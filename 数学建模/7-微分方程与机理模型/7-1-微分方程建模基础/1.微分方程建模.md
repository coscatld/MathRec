# 一、常微分方程问题的数学模型

在数学、力学、物理、化学等学科中已有许多经过实践检验的规律和定律，如牛顿运动定律、基尔霍夫电流和电压定律、物质的放射性规律、曲线的切线的性质等，这些都涉及某些函数的变化率。我们就可以根据相应的规律，列出常微分方程。

## 例题1. 建立物体冷却过程的数学模型

将某物体放置于空气中，在时刻 $t = 0$ 时，测量得它的温度为 $u_0 = 100\ ℃$，20 分钟后测量得它的温度为 $u_1 = 60\ ℃$。要求建立此物体的温度 $u$ 和时间 $t$ 的关系，并计算经过多长时间此物体的温度将达到 $30\ ℃$，其中我们假设空气的温度保持为 $20\ ℃$。

### 1. 建立微分方程模型
根据牛顿冷却定律：
$$\frac{du}{dt} = -k\,(u - u_a)$$
其中：

- $u(t)$ 是物体在时刻 $t$ 的温度。
- $u_a = 20$ 是空气温度（环境温度）。
- $k$ 是比例常数（$k > 0$）。
### 2. 求解微分方程
分离变量并积分：
$$\frac{du}{u-20} = -k\,dt$$
$$\int \frac{du}{u-20} = -\int k\,dt$$
$$\ln|u-20| = -kt + C_1$$
$$u-20 = Ce^{-kt}$$
$$u(t) = 20 + Ce^{-kt}$$
### 3. 代入初始条件确定参数
**条件1：** $t = 0$ 时，$u = 100$。
$$100 = 20 + Ce^{0} \;\Longrightarrow\; C = 80$$
此时方程为：
$$u(t) = 20 + 80e^{-kt}$$
**条件2：** $t = 20$ 时，$u = 60$。
$$60 = 20 + 80e^{-20k}$$
$$40 = 80e^{-20k}$$
$$e^{-20k} = \frac{1}{2}$$
解得 $k$：
$$-20k = \ln\left(\frac{1}{2}\right) = -\ln 2 \;\Longrightarrow\; k = \frac{\ln 2}{20} \approx 0.0347$$
所以，温度 $u$ 和时间 $t$ 的关系式为：
$$u(t) = 20 + 80e^{-\frac{\ln 2}{20}\,t}$$
或者写成更直观的形式（每 20 分钟温度差减半）：
$$u(t) = 20 + 80 \cdot \left(\frac{1}{2}\right)^{\frac{t}{20}}$$
### 4. 计算达到 30 ℃ 的时间
令 $u(t) = 30$：
$$30 = 20 + 80e^{-kt}$$
$$10 = 80e^{-kt}$$
$$e^{-kt} = \frac{1}{8}$$
两边取对数：
$$-kt = \ln\left(\frac{1}{8}\right) = -3\ln 2$$
$$t = \frac{3\ln 2}{k}$$
代入之前求出的 $k = \dfrac{\ln 2}{20}$：
$$t = \frac{3\ln 2}{\frac{\ln 2}{20}} = 3 \times 20 = 60\ \text{(分钟)}$$
