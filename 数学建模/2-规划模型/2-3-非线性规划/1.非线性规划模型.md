## 例1 投资决策问题

某企业有n个项目可供选择投资，并且至少要对其中一个项目投资。已知该企业拥有总资金A元，投资于第$i,i=1,2,\cdots,n$个项目需花资金$a_i$元，并预计可收益$b_i$元。试选择最佳投资方案。

解 设投资决策变量为

$$x_i = \begin{cases} 1 \text{决定会投资第i个项目} \\ 0 \text{决定不投资第i个项目} \end{cases}$$

则投资总额为$\sum_{i=1}^{n} a_i x_i$，投资总收益为$\sum_{i=1}^{n} b_i x_i$，因为该公司至少要对一个项目投资，所以投资金额不能超过A，故$0<\sum_{i=1}^{n} a_i x_i \leq A$。另外由于x只能取0和1，所以还有$x_i(1-x_i)=0,i=1,2,...,n$

所以最佳投资方案如下：
$$
\begin{aligned}
\max = & \frac{\sum_{i=1}^{n} b_i x_i}{\sum_{i=1}^{n} a_i x_i} \\
\text{s.t.} \quad & \begin{cases} 
0 < \sum_{i=1}^{n} a_i x_i \leq A \\ 
x_i(1 - x_i) = 0, \quad i = 1, 2, \dots, n 
\end{cases}
\end{aligned}
$$
## matlab语法
**Matlab**中非线性规划的数学模型写成以下形式：

$$\begin{aligned} &\min f(x) \\ s.t. &\begin{cases} \quad A \cdot x \leq b \\ \quad Aeq \cdot x = beq \\ \quad c(x) \leq 0 \\ \quad ceq(x) = 0 \\ \quad lb \leq x \leq ub \end{cases} \end{aligned}$$

其中$f(x)$是标量函数，$A,b,Aeq,beq,lb,ub$是相应维数的矩阵和向量，$c(x),ceq(x)$是非线性向量函数（nonlcon）。$[x,fval]=fmincon(fun,x0,A,b,Aeq,beq,lb,ub,nonlcon,options)$
>fun:目标函数的系数列向量；A,b:不等式约束条件的变量系数矩阵和常数项矩阵；Aeq,beq:等式约束条件的系数矩阵和常数项矩阵；lb,ub:决策变量的最小取值和最大取值

```matlab
% 1. 定义目标函数 (使用匿名函数)
% x(1) 对应 x1, x(2) 对应 x2, x(3) 对应 x3
fun = @(x) x(1)^2 + x(2)^2 + x(3)^2 + 8;

% 2. 设置初始猜测值 x0 (可以任意设，这里设为 [1, 1, 1])
x0 = [1, 1, 1];

% 3. 设置线性约束 (本题没有，设为空矩阵)
A = [];
b = [];
Aeq = [];
beq = [];

% 4. 设置变量的上下界
lb = [0, 0, 0]; % x1, x2, x3 >= 0
ub = [];        % 没有上界

% 5. 调用 fmincon 求解
% 注意：@mycon 是我们在下面定义的非线性约束函数
[x, fval] = fmincon(fun, x0, A, b, Aeq, beq, lb, ub, @mycon);

% 6. 输出结果
disp('最优解为:');
disp(x);
disp('目标函数的最小值为:');
disp(fval);

% ==========================================================
% 定义非线性约束函数 (局部函数，放在脚本的最下方)
function [c, ceq] = mycon(x)
    % 非线性不等式约束 c(x) <= 0
    c(1) = -x(1)^2 + x(2) - x(3)^2;
    c(2) = x(1) + x(2)^2 + x(3)^2 - 20;
    
    % 非线性等式约束 ceq(x) = 0
    ceq(1) = -x(1) - x(2)^2 + 2;
    ceq(2) = x(2) + 2*x(3)^2 - 3;
end
```
