# 最小生成树模型

## 一、问题定义

连通无向图 $G=(V,E)$ 的生成树满足：

- 包含全部顶点；
- 连通；
- 不含圈；
- 恰有 $|V|-1$ 条边。

最小生成树（MST）是在所有生成树中边权总和最小者：

$$
\min_{T\subseteq E}\sum_{e\in T}w_e
$$

典型问题：用最低成本连接全部城市、基站、管网节点或电力设施。

## 二、与其他模型的区别

| 模型 | 优化对象 |
|---|---|
| 最短路 | 某个起点到终点的路径 |
| 最短路径树 | 某一源点到所有节点的距离 |
| 最小生成树 | 连接全部节点的总建设成本 |
| TSP | 访问全部节点并回到起点的巡回 |

最小生成树不保证任意两点间的路径最短。

## 三、Kruskal 算法

1. 将边按权重升序排列；
2. 依次考察每条边；
3. 若加入后不形成圈，则保留；
4. 选满 $|V|-1$ 条边后停止。

通常使用并查集判断是否形成圈，复杂度约为：

$$
O(E\log E)
$$

```python
import networkx as nx

G = nx.Graph()
G.add_weighted_edges_from([
    ("A", "B", 4),
    ("A", "C", 2),
    ("B", "C", 1),
    ("B", "D", 5),
    ("C", "D", 8),
])

T = nx.minimum_spanning_tree(G, algorithm="kruskal")
print(list(T.edges(data=True)))
print(T.size(weight="weight"))
```

## 四、Prim 算法

1. 任取一个顶点构成初始树；
2. 在“树内顶点与树外顶点之间”的边中选权重最小者；
3. 把新顶点和该边加入树；
4. 直到全部顶点加入。

使用堆时复杂度约为：

$$
O(E\log V)
$$

## 五、正确性的关键性质

### 1. 割性质

对图的任意一个割，跨越该割的最小权边一定存在于某棵最小生成树中。

### 2. 圈性质

若一个圈中有一条边严格重于其他边，则该边不可能属于任何最小生成树。

## 六、建模注意事项

- 图不连通时不存在生成树，只能求最小生成森林；
- 方向通常应忽略或先说明如何转化；
- 若有固定建设费用和容量选择，可能变成混合整数网络设计问题；
- 权重相同可能产生多棵不同但总成本相同的 MST；
- 建成后的可靠性若要求冗余，树结构可能不够，需要增加备选边或可靠性约束。

## 七、结果检查

- [ ] 包含全部顶点；
- [ ] 边数为 $|V|-1$；
- [ ] 网络连通；
- [ ] 不存在圈；
- [ ] 总权重与程序输出一致；
- [ ] 若删除任一边，网络应断开。
