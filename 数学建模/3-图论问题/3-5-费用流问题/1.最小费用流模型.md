# 最小费用流模型
>在满足流量需求和边容量限制的前提下，让所有流量经过网络产生的总费用最小。

## 一、问题定义

每条边 $(i,j)$ 同时具有：

- 容量 $u_{ij}$；
- 单位流量费用 $c_{ij}$；
- 决策流量 $f_{ij}$。

目标是在满足供需和容量约束的条件下，使总费用最小：
$$
\min \sum_{(i,j)\in E}c_{ij}f_{ij}
$$
## 二、统一数学模型

容量约束：
$$
0\le f_{ij}\le u_{ij}
$$
节点平衡：

$$
\sum_j f_{ij}-\sum_j f_{ji}=b_i
$$
其中：

- $b_i>0$：供应节点；
- $b_i<0$：需求节点；
- $b_i=0$：中转节点；
- 必须满足 $\sum_i b_i=0$。

若要求输送指定流量 $F$，可令源点 $b_s=F$、汇点 $b_t=-F$。

## 三、与相邻模型的关系

| 模型 | 容量 | 费用 | 目标 |
|---|---|---|---|
| 最短路 | 可视为单位容量 | 有 | 一单位流的最低费用 |
| 最大流 | 有 | 无 | 流量最大 |
| 最小费用流 | 有 | 有 | 指定供需下费用最低 |
| 最小费用最大流 | 有 | 有 | 先使流量最大，再使费用最低 |
| 运输问题 | 供需约束 | 有 | 特殊的二部网络最小费用流 |

## 四、最小费用最大流

这是一个字典序目标：

1. 先最大化流量；
2. 在最大流量方案中最小化费用。

不能随意写成

$$
\max(\lambda F-C)
$$

除非 $\lambda$ 足够大并有严格依据，否则可能为了节约费用而牺牲最大流量。

详细算法、残量网络、手算示例和代码实现参见：[[2.最小费用最大流]]。

## 五、最短增广路思想

1. 初始化可行流；
2. 在残量网络中寻找单位费用最短的增广路；
3. 按瓶颈容量增广；
4. 更新正向和反向残量边；
5. 直到满足需求或不存在增广路。

反向边费用为原边费用的相反数，用于撤销之前的流量。若残量网络有负边，可使用 Bellman-Ford，或利用势函数将约化费用变为非负后使用 Dijkstra。

## 六、NetworkX 示例

```python
import networkx as nx

G = nx.DiGraph()

# demand < 0 表示供应，demand > 0 表示需求
G.add_node("factory", demand=-8)
G.add_node("hub", demand=0)
G.add_node("market", demand=8)

G.add_edge("factory", "hub", capacity=8, weight=3)
G.add_edge("hub", "market", capacity=8, weight=2)
G.add_edge("factory", "market", capacity=5, weight=8)

flow = nx.min_cost_flow(G)
cost = nx.cost_of_flow(G, flow)

print(flow)
print(cost)
```

## 七、适用场景

- 多产地、多销地运输；
- 生产分配和仓储中转；
- 公交调度与人员排班；
- 通信带宽分配；
- 钢管、物资等带容量的最低费用运输；
- 指派问题与二部图匹配。

## 八、建模注意事项

- 成本必须是单位流量成本；
- 总供给必须等于总需求，否则增加虚拟节点或允许缺货；
- 负费用允许存在，但不能存在可无限循环获利的负环；
- 不可分货物应加入整数约束；
- 若存在固定启用成本，模型会变成混合整数规划；
- 分段价格需要增加变量和约束，不能直接当作固定线性单价。
