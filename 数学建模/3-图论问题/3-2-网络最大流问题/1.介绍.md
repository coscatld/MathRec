#### matlab函数：
```Matlab

G = digraph(matrix);

% 2. 调用 maxflow 函数计算最大流和最小割
[mf, GF, cs, ct] = maxflow(G, vs, vt,"指定函数（augmentpath）");
```

| **现代参数 (maxflow)** | **说明 / 对应关系**                                                                        |
| ------------------ | ------------------------------------------------------------------------------------ |
| **`G`**            | 现代方法需先用 `digraph(matrix)` 将矩阵构建为**有向图对象 `G`**。                                       |
| **`vs`** 或 **`s`** | 源点（起始节点），支持节点索引数字或节点名称（如 `'A'`）。                                                     |
| **`vt`** 或 **`t`** | 汇点（目标节点），支持节点索引数字或节点名称。                                                              |
| **`mf`**           | **最大流量值**（标量数值）。                                                                     |
| **`GF`**           | 现代版返回包含实际流量的 **`digraph` 对象 `GF`**（仅保留有流量的边）。如需矩阵，可用 `adjacency(GF, 'weighted')` 转换。 |
| **`cs`, `ct`**     | **最小割的节点集合**：`cs` 为源点侧节点向量，`ct` 为汇点侧节点向量。                                            |
#### python函数
```python
from collections import deque

class FordFulkerson:
    def __init__(self, vertices_count):
        self.V = vertices_count
        # 邻接矩阵存储残量网络，初始化容量全为 0
        self.graph = [[0] * vertices_count for _ in range(vertices_count)]

    def add_edge(self, u, v, capacity):
        """添加一条有向边 u -> v，容量为 capacity"""
        self.graph[u][v] += capacity

    def _bfs(self, source, sink, parent):
        """寻找残量网络中是否存在从 source 到 sink 的增广路径"""
        visited = [False] * self.V
        queue = deque([source])
        visited[source] = True

        while queue:
            u = queue.popleft()
            for v in range(self.V):
                # 只有未访问过且残量容量大于 0 的边才能通行
                if not visited[v] and self.graph[u][v] > 0:
                    queue.append(v)
                    visited[v] = True
                    parent[v] = u
                    if v == sink:
                        return True
        return False

    def max_flow(self, source, sink):
        """计算从 source 到 sink 的最大流"""
        parent = [-1] * self.V
        max_flow = 0  # 累计最大流

        # 当残量网络中仍然存在增广路径时不断迭代
        while self._bfs(source, sink, parent):
            # 1. 找到当前增广路径上的瓶颈流量（最小剩余容量）
            path_flow = float('Inf')
            s = sink
            while s != source:
                path_flow = min(path_flow, self.graph[parent[s]][s])
                s = parent[s]

            # 2. 更新残量网络（正向边减去瓶颈流量，反向边加上瓶颈流量）
            v = sink
            while v != source:
                u = parent[v]
                self.graph[u][v] -= path_flow  # 正向容量减少
                self.graph[v][u] += path_flow  # 反向容量增加（撤销机制）
                v = parent[v]

            # 3. 累加本次找到的增广流量
            max_flow += path_flow

        return max_flow


# ================= 测试示例 =================
if __name__ == "__main__":
    # 创建包含 6 个节点（0 到 5）的图
    # 0: 源点 s, 5: 汇点 t
    g = FordFulkerson(6)

    # 添加有向边 (节点u, 节点v, 容量)
    g.add_edge(0, 1, 16)
    g.add_edge(0, 2, 13)
    g.add_edge(1, 2, 10)
    g.add_edge(1, 3, 12)
    g.add_edge(2, 1, 4)
    g.add_edge(2, 4, 14)
    g.add_edge(3, 2, 9)
    g.add_edge(3, 5, 20)
    g.add_edge(4, 3, 7)
    g.add_edge(4, 5, 4)

    source = 0
    sink = 5

    print(f"该网络的最大流为: {g.max_flow(source, sink)}")
```
