# 图论问题知识框架

> [!abstract] 学习主线
> 现实网络 $\rightarrow$ 点、边、权、方向、容量 $\rightarrow$ 识别标准问题 $\rightarrow$ 建立目标与约束 $\rightarrow$ 选择算法 $\rightarrow$ 验证和解释结果。

## 三、如何判断该用哪个模型

| 题目真正要求 | 识别信号 | 模型 |
|---|---|---|
| 两点间路线代价最小 | 从 $s$ 到 $t$、最短时间、最低路费 | 最短路 |
| 所有节点连通且建设费最低 | 铺设、架设、连接所有站点 | 最小生成树 |
| 有容量限制，输送量最大 | 管道容量、道路通行能力、最大吞吐量 | 最大流 |
| 完成指定流量且总费用最低 | 供需、容量、单位运输费 | 最小费用流 |
| 每条边至少走一次 | 巡街、清扫、投递、检查全部路段 | 中国邮递员 |
| 每个节点至少访问一次并返回 | 城市巡视、配送、旅行商 | TSP |
| 多辆车、有容量或时间窗 | 车辆、载重、服务时间、分组均衡 | VRP / mTSP |
| 左右两类对象一一配对 | 人岗匹配、任务分派 | 二部图匹配 |

> [!warning] 先看“覆盖对象”
> - 覆盖的是**边**：欧拉类问题；
> - 覆盖的是**点**：Hamilton/TSP 类问题；
> - 只关心指定起终点：最短路；
> - 只要求全网连通：生成树。

## 四、统一建模模板

### 1. 抽象网络

$$
G=(V,E)
$$

说明：

- $V$ 中每类顶点的现实含义；
- $E$ 在什么条件下存在；
- 图是否有向；
- 边权 $w_{ij}$ 表示距离、时间还是费用；
- 容量 $c_{ij}$、需求 $d_i$ 等额外属性。

### 2. 定义变量

常见变量：

$$
x_{ij}\in\{0,1\}
$$

表示是否选择边 $(i,j)$；

$$
f_{ij}\ge 0
$$

表示边 $(i,j)$ 上的流量。

同一符号不能在同一模型中同时表示选边变量和流量变量。

### 3. 写出目标函数

常见目标：

$$
\min \sum_{(i,j)\in E}w_{ij}x_{ij}
$$

或

$$
\max \sum_j f_{sj}-\sum_j f_{js}
$$

多目标问题应说明加权系数、主次关系或采用的 Pareto 方法。

### 4. 写出约束

重点检查：

- 流守恒；
- 容量限制；
- 供需平衡；
- 节点访问次数；
- 连通性与子回路；
- 整数性；
- 时间窗、载重和任务均衡。

### 5. 求解与验证

- 说明算法为什么适用；
- 输出目标值和具体路线/边集/流量；
- 将结果代回约束检查；
- 与简单基准、理论下界或其他算法比较；
- 做参数敏感性和稳健性分析。

## 五、算法选择速查

| 算法 | 适用条件 | 典型复杂度 |
|---|---|---|
| BFS | 无权图 | $O(V+E)$ |
| Dijkstra + 堆 | 非负边权、单源 | $O((V+E)\log V)$ |
| Bellman-Ford | 允许负权边、无负环最短路 | $O(VE)$ |
| Floyd-Warshall | 全源、规模不大 | $O(V^3)$ |
| Prim + 堆 | 最小生成树 | $O(E\log V)$ |
| Kruskal | 最小生成树、边表方便 | $O(E\log E)$ |
| Edmonds-Karp | 最大流、易实现 | $O(VE^2)$ |
| Dinic | 最大流、通常更高效 | $O(V^2E)$ |
| 最短增广路 | 最小费用流 | 取决于增广次数与最短路算法 |

## 六、建模检查清单

- [ ] 顶点、边、方向和权的含义清楚；
- [ ] 模型对应的是“点、边、连通、路径还是流量”；
- [ ] 目标函数与题意一致，量纲统一；
- [ ] 算法的前提条件满足；
- [ ] 不可达点、负权边、重边和自环已处理；
- [ ] 流守恒、容量、供需和整数约束完整；
- [ ] TSP/VRP 模型包含子回路消除；
- [ ] 输出能还原为现实方案；
- [ ] 对异常参数和数据变化进行了检验。
