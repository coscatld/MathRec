# Floyd 与 Bellman-Ford 算法

## 一、算法选择

| 问题 | 边权条件 | 推荐算法 |
|---|---|---|
| 无权单源最短路 | 等权 | BFS |
| 非负权单源最短路 | $w_{ij}\ge0$ | Dijkstra |
| 含负权边的单源最短路 | 不存在可达负环 | Bellman-Ford |
| 任意两点最短路 | 规模中小 | Floyd-Warshall |

## 二、Bellman-Ford 算法

对全部边重复执行松弛。若图有 $|V|$ 个顶点，则不含环的简单路径至多有 $|V|-1$ 条边，因此进行 $|V|-1$ 轮松弛即可。

若再进行一轮仍能松弛，说明存在从源点可达的负权环，此时最短路没有有限解。

```python
def bellman_ford(nodes, edges, start):
    # edges = [(u, v, weight), ...]
    dist = {node: float("inf") for node in nodes}
    prev = {node: None for node in nodes}
    dist[start] = 0

    for _ in range(len(nodes) - 1):
        changed = False
        for u, v, weight in edges:
            if dist[u] + weight < dist[v]:
                dist[v] = dist[u] + weight
                prev[v] = u
                changed = True
        if not changed:
            break

    for u, v, weight in edges:
        if dist[u] + weight < dist[v]:
            raise ValueError("存在从源点可达的负权环")

    return dist, prev
```

复杂度：

$$
O(VE)
$$

## 三、Floyd-Warshall 算法

令 $D_{ij}^{(k)}$ 表示只允许顶点 $1,\ldots,k$ 作为中间点时，$i$ 到 $j$ 的最短距离：

$$
D_{ij}^{(k)}
=\min\left(
D_{ij}^{(k-1)},
D_{ik}^{(k-1)}+D_{kj}^{(k-1)}
\right)
$$

```python
def floyd_warshall(distance):
    dist = [row[:] for row in distance]
    n = len(dist)

    for k in range(n):
        for i in range(n):
            for j in range(n):
                dist[i][j] = min(
                    dist[i][j],
                    dist[i][k] + dist[k][j],
                )

    if any(dist[i][i] < 0 for i in range(n)):
        raise ValueError("图中存在负权环")

    return dist
```

复杂度：

$$
O(V^3)
$$

空间复杂度：

$$
O(V^2)
$$

## 四、注意事项

- 初始化时 $D_{ii}=0$；
- 不存在的边设为 $\infty$；
- 负权边不等于负权环；
- 若只需要单个源点且边权非负，Floyd 通常不如 Dijkstra；
- 若需要恢复路径，应额外维护 `next` 或前驱矩阵。
