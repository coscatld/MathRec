# 最短路与 Dijkstra 算法

## 一、问题定义

在赋权图 $G=(V,E)$ 中，路径 $P$ 的长度为：

$$
w(P)=\sum_{e\in P}w(e)
$$

最短路问题是在所有从起点 $s$ 到终点 $t$ 的路径中，寻找权值之和最小的路径。

常见类型：

- 单点对：求指定 $s$ 到 $t$；
- 单源：求 $s$ 到所有顶点；
- 全源：求任意两点之间的距离；
- 多约束路径：除距离外还有时间、费用、换乘次数等约束。

## 二、0-1 规划模型

定义：

$$
x_{ij}=
\begin{cases}
1,&\text{选择弧 }(i,j)\\
0,&\text{否则}
\end{cases}
$$

目标函数：

$$
\min \sum_{(i,j)\in E}w_{ij}x_{ij}
$$

流守恒：

$$
\sum_jx_{ij}-\sum_jx_{ji}=
\begin{cases}
1,&i=s\\
-1,&i=t\\
0,&\text{其他节点}
\end{cases}
$$

## 三、Dijkstra 算法

### 1. 适用条件

Dijkstra 适用于：

- 单源最短路；
- 有向图或无向图；
- 所有边权均非负。

若存在负权边，应改用 [[2.Floyd与Bellman-Ford算法#二、Bellman-Ford 算法|Bellman-Ford]]。

### 2. 松弛操作

若已经知道 $s$ 到 $u$ 的当前距离 $d[u]$，则经过边 $(u,v)$ 到达 $v$ 的候选距离为：

$$
d[u]+w(u,v)
$$

若

$$
d[u]+w(u,v)<d[v]
$$

则更新：

$$
d[v]\leftarrow d[u]+w(u,v)
$$

并记录 $v$ 的前驱为 $u$。

### 3. 算法步骤

1. 初始化 $d[s]=0$，其余距离为 $\infty$；
2. 从未确定的顶点中取出距离最小的 $u$；
3. 将 $u$ 的最短距离标记为确定；
4. 对 $u$ 的所有邻点执行松弛；
5. 重复直到队列为空或目标点已确定。

使用优先队列时，复杂度约为：

$$
O((V+E)\log V)
$$

## 四、Python 实现

```python
import heapq


def dijkstra(graph, start):
    """graph[u] = [(v, weight), ...]"""
    dist = {node: float("inf") for node in graph}
    prev = {node: None for node in graph}
    dist[start] = 0
    queue = [(0, start)]

    while queue:
        current_dist, u = heapq.heappop(queue)

        # 丢弃已经失效的队列记录
        if current_dist != dist[u]:
            continue

        for v, weight in graph[u]:
            new_dist = current_dist + weight
            if new_dist < dist[v]:
                dist[v] = new_dist
                prev[v] = u
                heapq.heappush(queue, (new_dist, v))

    return dist, prev


def reconstruct_path(prev, start, target):
    path = []
    current = target

    while current is not None:
        path.append(current)
        if current == start:
            return path[::-1]
        current = prev[current]

    return []  # target 不可达
```

## 五、NetworkX

```python
import networkx as nx

G = nx.Graph()
G.add_weighted_edges_from([
    ("A", "B", 4),
    ("A", "C", 2),
    ("B", "C", 1),
    ("B", "D", 5),
    ("C", "D", 8),
])

path = nx.shortest_path(G, "A", "D", weight="weight")
distance = nx.shortest_path_length(G, "A", "D", weight="weight")

print(path, distance)
```

## 六、MATLAB

```matlab
s = [1 1 2 2 3];
t = [2 3 3 4 4];
w = [4 2 1 5 8];

G = graph(s, t, w);
[P, d] = shortestpath(G, 1, 4, "Method", "positive");
```

常用 `Method`：

- `"unweighted"`：无权图；
- `"positive"`：非负权；
- `"mixed"`：有正负权，但不能有负环；
- `"acyclic"`：有向无环图。

## 七、结果验证

- 路径中的相邻节点必须有边；
- 路径权重之和应等于输出距离；
- 不可达节点的距离应为 $\infty$；
- 无向图数据是否误建成有向图；
- 非负权条件是否满足；
- 若有多条等长路径，算法可能只返回其中一条。
