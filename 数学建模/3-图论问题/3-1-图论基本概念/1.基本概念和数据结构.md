# 二、最短路径-迪杰斯特拉算法
## 1.数学原理
决策变量为$x_{ij}$,当$x_{ij}$=1，说明$v_iv_j$位于顶点$v_i$至顶点 $v_j$点最短路上；否则$v_iv_j$=0.
其目标函数为$min \sum{w_{ij}v_{ij}}$
## 2.步骤
**第 1 步：初始化**
- 创建一个距离数组 `dist`。将起点到自身的距离设为 **0**，即 `dist[s] = 0`。 
- 将起点到其他所有节点的距离设为**无穷大**（$\infty$）。    
- 所有节点初始状态均为“未访问”。
**第 2 步：寻找当前最短节点**
- 在所有“未访问”的节点中，找到当前 `dist` 值最小的节点，设为 $u$。
- 将节点 $u$ 标记为“已访问”（将其划入集合 S）。    
**第 3 步：更新邻居节点距离（松弛操作）**
- 遍历节点 $u$ 的所有“未访问”的相邻节点 $v$。    
- 计算经过 $u$ 到达 $v$ 的新距离：$D_{new} = dist[u] + w(u, v)$，其中 $w(u, v)$ 是边 $u-v$ 的权重。    
- 如果 $D_{new} < dist[v]$，则更新 $dist[v] = D_{new}$。    
**第 4 步：循环迭代**
- 重复**第 2 步**和**第 3 步**，直到所有节点都被标记为“已访问”，或者目标节点被访问。
## 3.matlab求解函数
\[P,d]=shortestpath(G,start,end,\['method',algorithm])
- G：求解的图G=graph(起点的矩阵,终点的矩阵,权重的矩阵)；
- start：起点；
- end：终点；
- \['method',algorithm]：求解方法（auto、unweighted、postive、mixed）
- P：最短路径经过的节点序列
- d：最短路径
## 4.python求解函数和相应的库
### 法一：手动实现
```python
import heapq
from collections import defaultdict


def dijkstra(graph, start):
    """
    Dijkstra 算法 - 手动实现
    graph: dict, graph[u] = [(v, weight), ...]
    返回: dist (到各点最短距离), prev (前驱节点，用于重建路径)
    """
    # 初始化
    dist = {node: float('inf') for node in graph}
    dist[start] = 0
    prev = {node: None for node in graph}
    
    # 优先队列: (当前距离, 节点)
    pq = [(0, start)]
    visited = set()
    
    while pq:
        d, u = heapq.heappop(pq)
        
        if u in visited:
            continue
        visited.add(u)
        
        # 松弛操作
        for v, weight in graph[u]:
            if v not in visited:
                new_dist = d + weight
                if new_dist < dist[v]:
                    dist[v] = new_dist
                    prev[v] = u
                    heapq.heappush(pq, (new_dist, v))
    
    return dist, prev


def get_path(prev, target):
    """根据前驱数组重建最短路径"""
    path = []
    cur = target
    while cur is not None:
        path.append(cur)
        cur = prev[cur]
    return path[::-1]


# ==================== 示例图 ====================
graph = {
    'A': [('B', 4), ('C', 2)],
    'B': [('A', 4), ('C', 1), ('D', 5)],
    'C': [('A', 2), ('B', 1), ('D', 8), ('E', 10)],
    'D': [('B', 5), ('C', 8), ('E', 2), ('F', 6)],
    'E': [('C', 10), ('D', 2), ('F', 3)],
    'F': [('D', 6), ('E', 3)],
}

# 运行
start = 'A'
dist, prev = dijkstra(graph, start)

print("=" * 45)
print(f"从节点 '{start}' 出发的最短距离：")
print("-" * 45)
for node in sorted(graph.keys()):
    path = get_path(prev, node)
    path_str = " -> ".join(path)
    print(f"  {start} -> {node}: 距离 = {dist[node]:2d}, 路径 = {path_str}")

print("=" * 45)
```
### 法二：networkx
```python
import networkx as nx

# 创建有向图（无向图用 nx.Graph()）
G = nx.DiGraph()

# 添加边
edges = [
    ('A', 'B', 4), ('A', 'C', 2),
    ('B', 'C', 1), ('B', 'D', 5),
    ('C', 'D', 8), ('C', 'E', 10),
    ('D', 'E', 2), ('D', 'F', 6),
    ('E', 'F', 3),
]
G.add_weighted_edges_from(edges)

# 计算最短路径和距离
start = 'A'
target = 'F'

# 单源最短路径
lengths = nx.single_source_dijkstra_path_length(G, start)
paths = nx.single_source_dijkstra_path(G, start)

print("NetworkX Dijkstra 结果：")
for node in sorted(G.nodes()):
    print(f"  {start} -> {node}: 距离 = {lengths[node]}, 路径 = {' -> '.join(paths[node])}")

# 两点之间
path = nx.dijkstra_path(G, start, target)
length = nx.dijkstra_path_length(G, start, target)
print(f"\n特定路径 {start} -> {target}: 距离 = {length}, 路径 = {' -> '.join(path)}")
```
### 法三：scipy
```python
from scipy.sparse import csr_matrix
from scipy.sparse.csgraph import dijkstra

# 邻接矩阵（inf 表示无边）
graph_matrix = [
    [0, 4, 2, 0, 0, 0],
    [4, 0, 1, 5, 0, 0],
    [2, 1, 0, 8, 10, 0],
    [0, 5, 8, 0, 2, 6],
    [0, 0, 10, 2, 0, 3],
    [0, 0, 0, 6, 3, 0],
]
graph = csr_matrix(graph_matrix)

# 从节点 0 (A) 出发到所有节点的最短距离
dist_matrix, predecessors = dijkstra(csgraph=graph, directed=True, indices=0, return_predecessors=True)
print(dist_matrix)  # [0, 3, 2, 8, 10, 13]
```
