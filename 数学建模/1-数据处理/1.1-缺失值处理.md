>数据集中不含缺失值的变量称为完全变量，数据集中含有缺失值的变量成为不完全变量。因此数据缺失类型可以分为完全随机缺失，随机缺失和非随机缺失

**完全随机缺失**：所有变量缺失的概率都是相同的，随机的缺失不依赖于其他变量。
**随机缺失**：数据的缺失与其他完全变量有关，与自身取值无关。
**非随机缺失**：数据的缺失与不完全变量有关自身的取值无关。一般分为只与自身有关，或与其他完全变量以及自身相关两种情况。
# 一、处理方法
主要分为：删除处理、值填充，回归插值，KNN填充
## 1.删除处理
```python
DataFrame.dropna(
    axis,  # 为0时表示删除行，为1时表示删除列
    thresh,  # 阈值，非空数据小于这个数的时候删除
    how,  # 删除方式，为any表示只有一个为空就删除整行/整列，为all表示整行/整列全为空才删除
    subset,  # 子集，只关注这几列的缺失值情况，其他列不纳入how和thresh的考虑范围
    inplace  # 为True时直接修改原数据表，为False时表示另存为，不修改原数据表
)

DataFrame.drop(
    labels,  # 删除指定名字的几行或者几列
    axis,  # 为0表示删除行，对应的labels就是行的索引，为1表示删除列，对应的就是列的列名
    inplace  # 同上
)
```
