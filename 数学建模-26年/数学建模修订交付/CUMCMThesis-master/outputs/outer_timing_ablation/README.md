# 外层筛选时点消融

本实验以 `main.tex` 对应调度程序为母模型，保留上一轮外层候选筛选的全部结果，仅新增第三问与第四问滚动版各两次回测。

## 四组实验

| 模式 | 零时 | 6、12、18 时 | 每 334 天筛选次数 |
|---|---|---|---:|
| 仅零时筛选 `midnight_only` | 原候选集合统一回放筛选 | 普通情景 LP | 334 |
| 仅日内筛选 `intraday_only` | 普通情景 LP | 原候选集合统一回放筛选 | 1002 |

两种模式均保留每日四次合法外层更新。未筛选时点仍以该策略自己的当前储能和零时计划求解母模型，不能跳过更新、恢复旧状态或拼接原主案执行数组。“仅零时筛选”仍有日内 LP 修订，不等于第二问的日前固定采购。

候选菜单、28 条历史情景、配对价荷关系、预测器、原贪心执行器、结算口径、终端项、初始储能均沿用上一轮。额外 CVaR 与备用保持关闭，没有增加实时控制器。

## 事前确定的策略选择规则

第二问和第四问日前版按用户要求固定保留母模型。第三问和第四问滚动版，分别比较母模型、当前全时点筛选、仅零时筛选、仅日内筛选。

以 334 天实际计划费、调整费与紧急费之和为主要指标。当前全时点筛选为已接受方案；新方案只有在实际费用至少改善一分钱以上，并且评价期末统一库存修正不改变最佳排序时才替代它。数值同分保留当前方案。紧急补购与月度差异如实报告，不事后增加风险或备用门槛。

终端项先用于每次候选评分；真实总账单不包含它。评价期比较只在终点按同一系数另计算一次库存修正，不能累计重叠回放窗口的终端罚项或估计收益。

该区间为已用于研究开发的 2025-02-01 至 2025-12-31，选择结果属于开发期策略选择，不声称为独立留出测试或未来节费保证。

## 结果与证据

- `experiment.json`：事前实验定义、保护的输入清单、四组汇总。
- `q3_midnight_only*`、`q3_intraday_only*`、`q4_3_midnight_only*`、`q4_3_intraday_only*`：完整执行数组、逐决策合同及评分、费用汇总。

- `run_manifest.json`：运行命令、环境、输入/输出/代码 SHA-256。
- `policy_checks.json`：兼容性、时点开关及未来信息隔离检查。
- `audit.json`：完整输出的独立费用、状态、合同、评分和哈希审计。
- `时点消融与最终策略.md`：中文对照报告。

运行器检查母模型、原正文、数据、表格和上一轮结果共用文件在运行前后的哈希不变。最终策略以配置及结果路径保存，不覆盖母模型或丢弃上一轮增强结果。
