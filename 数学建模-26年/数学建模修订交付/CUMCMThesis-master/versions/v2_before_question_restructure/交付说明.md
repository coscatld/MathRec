## 附件5的最终位置与填报口径

已填写文件位于论文目录上一级 `附件/附件5/`：`result1.xlsx`、`result2.xlsx`、`result3.xlsx`、`result4-2.xlsx`、`result4-3.xlsx`。`originals/附件5/` 中的是空白原模板，不能作为填报结果提交。

购电标签和顺序逐字保留，从 `0:10-0:20` 开始，以原文表示的次日 `0:00-0:10` 结束；问题一末标签为 `0:00+1-0:10+1`，其他文件为 `0:00-0:10+1`。数组严格按源样本列序填入，没有循环移位。

模型把源采样值解释为右端点的十分钟平均功率，这是**建模假设**，并非题目明确事实。例如数组第0项对应源00:10、物理00:00—00:10，填写到模板首个购电格。物理末段为当天23:50—24:00，不另取次日数据。指定时段表、四小时汇总和紧急区间使用同一物理索引，完整映射见 `data/time_mapping.csv`。

所有计划页的“全天购电费”为日前计划费用。调整页保存最后生效的常规购电总量，并非增量；其“全天购电费”为含计划、调整及紧急购电的实际总费用。问题二和问题四-2没有调整页，其完整总费用见 `data/daily_summary.csv` 和论文。内层控制不能在题目规定时点之外修订常规购电。

电量单位为kWh、费用单位为元。显示电量3位小数、费用2位，底层保留完整数值。四小时内充、放电同时为正可表示不同十分钟时段分别发生充放电。无紧急购电的日期填“无”、0。详细字段说明见 `data/附件5填写说明.md`。

## 结算与比较边界

主口径为原计划全额付款、下调另付50%违约费、上调按1.5倍付费、紧急购电按5倍付费。在“不退款、正电价、免费弃余”条件下，下调受到支配。退款解释保留为独立敏感性，不因费用更低而更换主口径。附件4实际价格用于结算，尚未揭示的价格不进入当前决策。

80%采购分位数、70%日内上调阈值及价格加权分位数解释无储能单时段的结算机制，不能直接作为全天储能策略或备用系数。规划—执行偏差只计真实结算项目，不混入CVaR、终端惩罚；滚动诊断窗口重叠，不能将其差值求和当作年度节费或全局最优差距。

本轮完成23个命名对照及2个主策略引用，保存为 `data/experiments_v2.json` 中25个完成条目。部分等同配置复用同一结果，不把命名条目数当作独立仿真次数。对照涵盖28与12场景、场景期望与点预测、备用单独作用、固定与自适应风险/备用、一月匹配的保守程度、仅零时计划、状态/光伏/负荷反馈分解、规则控制、内层LP、跨日价值及退款解释。2—12月对照不会回写主案选择；显式计入未来修订机会的非预见性场景树仍属于尚未实现的增强。

两项规划—执行诊断已完成。内层LP诊断覆盖题目四个指定日期、每日期四个发布时点，共16个决策点，规则与LP控制器各回放448条历史场景轨迹。计算结果在 `data/inner_gap_v2.json/csv`，原版诊断在 `data/execution_gap_v1.json/csv/npz`。它们不声称所有情况下LP费用更低或规划偏差更小。

## 复现

在本目录使用PowerShell运行：

```powershell
powershell -ExecutionPolicy Bypass -File code/run_revision.ps1
```

默认复用 `selection_v2.json` 和四份 `prepared_v2_*.npz`，依次执行主案、对照、图表、数值检查、Excel导出与核对。原版诊断可复用；内层回放按保存的配置、源码和数据哈希判断是否刷新。全部步骤不调用LaTeX。

- `-Recalibrate`：明确重跑一月预测/控制选择及相关对照，仍不使用2—12月费用选参。
- `-SkipExperiments`：复用已完整保存的对照，检查冻结选择、模型及预测输入哈希；相关内容改变时必须重算。
- `-RecomputeDiagnostics`：重新计算原版偏差与内层控制回放。
- `-SkipExcel`：重算数据和论文资产，保留现有工作簿；此时工作簿可能不对应重算后的JSON，应另行导出核对后再提交。
- `-Workers 1` 或 `-Workers 2`：设置主案和对照的并行进程数。

默认数据读取/Excel核对使用Codex附带Python，优化使用系统中含SciPy的Python，工作簿使用附带Node.js的 `@oai/artifact-tool`。可用 `-DataPython`、`-SolverPython`、`-NodeExecutable` 指定环境。Python依赖见 `code/requirements.txt`；`code/node_modules` 是指向已有依赖的目录联接，不是待打包的第三方源码。

新增入口已检查PowerShell语法；各计算、制图、导出和核对步骤本轮分别执行，未为测试入口重复整套年度实验。安装LaTeX后由用户自行编译 `main.tex` 和需要的AI详情材料。
