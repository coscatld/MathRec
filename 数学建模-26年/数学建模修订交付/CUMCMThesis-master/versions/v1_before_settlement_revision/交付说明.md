## 模型中的明确选择

1. 主结算按“计划全额付款 + 下调50%违约费 + 上调1.5倍费用 + 紧急5倍费用”，不假设退款。允许免费弃余，因此下调在优化中受到支配。另算了取消计划并退款的解释，作为独立敏感性结果，不混入附件5。
2. 附件4按实际交易电价处理，日前优化不能看未来实际价格；交易结算使用真实价格。
3. 两阶段模型中购电、储能参考动作共享，紧急量按场景补救；实际储能使用当前观测反馈。该限制策略类不是任意因果控制的全局最优。
4. 风险权重和备用是事先给定的偏好。对照实验显示，增加风险偏好可减少紧急量，但可能同时增加总电费和日总费尾部；正文没有把所有增强项都写成必然更优。

## 复现代码

所有源代码在 `code/`，未只留下结果文件。

```text
python code/data_forecast.py
python code/optimize_dispatch.py --case all
python code/run_experiments.py
python code/make_paper_assets.py
node code/export_workbooks.mjs
python code/verify_workbooks.py
```

本机可运行 `powershell -ExecutionPolicy Bypass -File code/run_all.ps1`，脚本会区分读取附件的 bundled Python 与含 SciPy 的系统 Python；不会调用 LaTeX。可选 `-SkipExperiments` 复用已有实验结果，或 `-SkipExcel` 只重算数据和论文图表。

本次计算环境：Python 3.12.3、NumPy 2.4.2、SciPy 1.17.0、Matplotlib 3.10.8；附件读取与Excel核对使用 bundled Python 3.12.14、NumPy 2.3.5、openpyxl 3.1.5；工作簿由 bundled Node.js 的 `@oai/artifact-tool` 导入原模板后写出。其他机器可在一个Python环境安装 `code/requirements.txt`；Excel导出需可用的 `@oai/artifact-tool`，无需重新安装到现有工程。
